## Run

**Settings.** The next cell holds the switches a user sets (each can also come from the
environment variable in brackets):

| Setting | Values |
|---|---|
| `RL_DATASET` | `synthetic` (default) · `leie` · `scale` · `files` (`RL_EXTRACTED`, `RL_WATCHLIST`) · `delta` inputs need `IO_FORMAT = "delta"` |
| `IO_FORMAT` (`RL_IO_FORMAT`) | `csv` (default, for display) · `parquet` · `delta` |
| `EXHAUSTIVE` (`RL_EXHAUSTIVE`) | `False` (default: the recall-oriented blocking rules) · `True` (every same-type pair, streamed in chunks) |
| `ADDRESS_STANDARDIZER` (`RL_ADDRESS_STANDARDIZER`) | `usaddress` (default) · `given` · `smarty` |
| `BASELINE` (`RL_BASELINE`) | `False` (default) · `True`: run the current method beside B1 in the self-checks |
| `SELF_CHECK` (`RL_SELF_CHECK`) | `True` (default): held-out identifier check and noise test |
| `INCREMENTAL` (`RL_INCREMENTAL`) | `False` (default) · `True` (Delta only): score only new or changed extracted rows |

Every other number is in `RunConfig` (section 0) and goes to the manifest. The cells after it
run the whole pipeline once (`run_pipeline`), print what each step did, run the self-checks and
write the tables and the workbook; the timing and peak memory of every step go to the manifest.
