Load notes in real Excel

On Notes, enter claim number, note ID and reading order. Copy the whole note from Notepad, then click Paste whole note. The button captures long text before splitting it into safe storage parts. Or use Import TXT files. Select note opens Note Register; choose a row and Open selected note.

Prepare optional AI drafts

Open the current note. Ask Copilot to follow AI Instructions and fill AI Queue plus AI Analysis Input. Check the note and processed parts. Once Copilot finishes, click Save queue snapshot. Load next AI draft then fills this same form. Manual entry works even when Copilot is unavailable.

Recent AI Analysis retains the last five distinct notes pasted. Older analysis expires; notes, accepted annotations and unfinished candidates remain.

Corrections, drafts and recovery

Previous entry opens your latest accepted revision. Edit and re-attest to replace that revision; history is retained. Save draft keeps unfinished work separately. Resume saved draft restores it. Leaving edited cells asks Save draft / Discard / Cancel. Delete blocks orphaning an entity's accepted references.

Real Excel saves must succeed before the workbench reports acceptance. There is a pre-write recovery copy in TEMP. Use a disposable QA copy for failure tests.
